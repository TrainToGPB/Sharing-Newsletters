# 벤치마크 결과: 지식과 STEM

> 원본: [arxiv.org/abs/2505.18454](https://arxiv.org/html/2505.18454v2)

앞 편에서 정의한 HRPO 의 보상·롤아웃·정책 목적함수가 실제로 어떤 점수로 이어지는지 확인할 차례다. 평가는 크게 두 갈래로 나뉜다. 외부 지식을 끌어와야 답할 수 있는 **지식 집약형 QA** 와, 검색 없이 내부 추론만으로 푸는 **STEM 문제풀이**. 두 영역 모두에서 같은 결론이 반복된다. 1.5B·3B 의 작은 백본을 RL 로 다듬는 것만으로도 7B 풀 파라미터 베이스라인과 비교 가능한 수준에 도달한다는 것이다.

## 실험 셋업

백본은 Qwen2.5-1.5B-Instruct 와 Qwen2.5-3B-Instruct 두 사이즈를 쓴다. 비교 기준선으로 Qwen2.5-7B-Instruct (지식) / Qwen2.5-7B (STEM) 도 같이 평가한다. 작은 모델이 큰 모델을 따라잡거나 넘는지를 보겠다는 의도가 셋업 단계에서 명확하다.

지식 영역에서는 검색 엔진을 단순화하기 위해 E5 임베딩으로 위키피디아 문서를 인코딩하고 질의당 top-3 패시지를 컨텍스트로 붙인다. 학습 데이터는 NQ 와 HotpotQA 의 train split 을 섞어 만들고, 평가는 NQ, TriviaQA, HotpotQA, 2WikiMultiHopQA, Bamboogle 다섯 셋이다. NQ 와 TriviaQA 는 단일 홉, 뒤 셋은 멀티홉 비중이 높다. 같은 모델·같은 검색기로 학습한 정책이 분포 밖 멀티홉까지 일반화되는지가 관건이다.

STEM 은 검색이 빠지고 수학·과학·상식 추론으로 평가한다. GSM8k 와 MATH 는 각각의 train split 으로 RL 을 돌리고, MMLU-STEM 과 ARC-Challenge 는 학습 split 이 없어 보조 train set 으로 대체한다. 평가 지표는 모두 EM (exact match) 또는 정답률이고, 추론 과정에서 생성되는 latent step 의 hyperparameter (잠재 토큰 수, KL 계수, sampling 온도 등) 는 두 영역에 동일한 디폴트를 쓴다.

비교 베이스라인은 두 카테고리에서 조금 다르게 잡힌다.

- **지식**: 검색 없이 바로 답하는 QA (Direct), Chain-of-Thought (CoT), 반복 검색-추론 루프 IRCoT, agent 식 Search-o1, 단순 RAG, supervised fine-tuning (SFT), 그리고 RL 계열 PPO·GRPO·HRPO.
- **STEM**: 7B 이상의 수학·과학 특화 LLM (DeepSeekMath-7B, Gemma-2-9B, Qwen2.5-7B, MAmmoTH2-7B/8B), SFT, distilled CoT, PPO, GRPO, HRPO.

두 카테고리 모두에서 PPO·GRPO 는 HRPO 와 같은 RL 백본·같은 train split 으로 비교한다. 즉 알고리즘 자체의 효과만 떼어서 본다.

## 지식 집약 (Knowledge) 벤치마크

다음은 5개 QA 데이터셋의 Exact Match 점수이다. 굵게 표기는 백본별 (1.5B / 3B) 최고치를 의미한다.

| 모델·방법 | NQ | TriviaQA | HotpotQA | 2WikiMQA | Bamboogle | 평균 |
| --- | --- | --- | --- | --- | --- | --- |
| **Qwen2.5-7B-Instruct** | | | | | | |
| QA | 0.134 | 0.408 | 0.183 | 0.250 | 0.120 | 0.219 |
| CoT | 0.048 | 0.185 | 0.092 | 0.111 | 0.232 | 0.134 |
| IRCoT | 0.224 | 0.478 | 0.133 | 0.149 | 0.224 | 0.242 |
| Search-o1 | 0.151 | 0.443 | 0.187 | 0.176 | 0.296 | 0.251 |
| RAG | 0.349 | 0.585 | 0.299 | 0.235 | 0.208 | 0.335 |
| **Qwen2.5-1.5B-Instruct** | | | | | | |
| SFT | 0.094 | 0.193 | 0.129 | 0.210 | 0.024 | 0.130 |
| RAG | 0.288 | 0.477 | 0.228 | 0.203 | 0.072 | 0.254 |
| PPO | 0.327 | 0.527 | 0.256 | 0.242 | 0.184 | 0.307 |
| GRPO | 0.293 | 0.480 | 0.202 | 0.213 | 0.120 | 0.261 |
| HRPO (Ours) | **0.364** | **0.553** | **0.273** | **0.276** | **0.216** | **0.337** |
| **Qwen2.5-3B-Instruct** | | | | | | |
| SFT | 0.249 | 0.292 | 0.186 | 0.248 | 0.112 | 0.217 |
| RAG | 0.348 | 0.544 | 0.255 | 0.226 | 0.080 | 0.291 |
| PPO | 0.356 | 0.563 | 0.304 | 0.293 | 0.240 | 0.351 |
| GRPO | 0.381 | 0.570 | 0.308 | 0.303 | 0.272 | 0.367 |
| HRPO (Ours) | 0.378 | **0.593** | **0.316** | **0.318** | **0.296** | **0.380** |

3B HRPO 의 평균이 0.380 이다. 같은 표에서 가장 강한 7B 베이스라인인 RAG 가 0.335 이니 +4.5%p 격차다. 모델 사이즈를 절반 이하로 줄이고도, 그것도 같은 검색 컨텍스트를 받는 조건에서, 더 정확하게 답을 맞춘다. 1.5B HRPO 의 평균 0.337 도 같은 7B RAG 와 사실상 동률이고, 같은 백본의 PPO (0.307) 보다 +3.0%p 위다.

RL 알고리즘끼리 비교하면 결과가 더 흥미롭다. GRPO 는 1.5B 에서 PPO 보다 4.6%p 떨어지지만 (0.261 vs 0.307), 3B 에서는 1.6%p 앞선다 (0.367 vs 0.351). 작은 모델일수록 sparse reward 와 limited rollout 의 영향이 누적되어 group-relative advantage 의 분산이 커지는 패턴으로 읽힌다. HRPO 는 두 사이즈 모두에서 RL 베이스라인 가운데 가장 높고, 사이즈가 작아질 때의 성능 하락도 가장 완만하다. 잠재 토큰을 통해 매 스텝 더 풍부한 표현을 KV cache 에 남기는 구조가, 작은 백본의 좁은 표현 공간을 보완하는 역할을 한다고 해석할 수 있다.

데이터셋별로 보면 효과가 두드러지는 곳이 있다. NQ 와 2WikiMQA 는 질문이 모호하거나 멀티홉이라 단순 RAG 만으로는 정답을 좁히기 어려운데, 여기서 HRPO 가 가장 큰 마진을 낸다. 3B 의 경우 NQ 에서 PPO 대비 +2.2%p, 2WikiMQA 에서 +2.5%p, Bamboogle 에서 +5.6%p 이다. 반대로 단순 1-hop 사실 확인이 대부분인 TriviaQA 에서는 마진이 +1.5~3.0%p 정도로 줄어든다. RL 이 주는 이득이 추론 단계가 깊어질수록 커진다는 일관된 신호다.

또 하나 짚을 점은 SFT 의 자리다. 1.5B SFT 평균 0.130, 3B SFT 평균 0.217. 같은 train set 으로 학습했음에도 RL 계열에 크게 못 미친다. 검색 결과를 받아 정답을 그대로 따라쓰는 방식만으로는 멀티홉 질의에서 어떤 패시지를 우선시할지 학습되지 않는다. RL 이 outcome reward 를 통해 사실상 검색-추론 정책을 다듬어 주는 셈이다.

## STEM 벤치마크

수학·과학 추론에서도 같은 표 구조를 따른다. 굵게는 백본별 최고치, 그리고 1.5B / 3B 두 사이즈가 7B 이상 베이스라인과 어디까지 좁혀지는지를 함께 보면 된다.

| 모델·방법 | GSM8k | MATH | MATH500 | MMLU-ST | ARC-C | 평균 |
| --- | --- | --- | --- | --- | --- | --- |
| **7B 이상 LLM** | | | | | | |
| DeepSeekMath-7B | 0.642 | 0.362 | 0.346 | 0.565 | 0.678 | 0.519 |
| Gemma-2-9B | 0.707 | 0.377 | 0.364 | 0.651 | 0.682 | 0.556 |
| Qwen2.5-7B | 0.854 | 0.498 | 0.464 | 0.723 | 0.637 | 0.635 |
| MAmmoTH2-7B | 0.684 | 0.367 | 0.396 | 0.624 | 0.817 | 0.578 |
| MAmmoTH2-8B | 0.704 | 0.358 | 0.732 | 0.642 | 0.822 | 0.652 |
| **Qwen2.5-1.5B-Instruct** | | | | | | |
| SFT | 0.560 | 0.300 | 0.302 | 0.403 | 0.602 | 0.433 |
| Distilled CoT | 0.706 | 0.503 | - | - | - | - |
| PPO | 0.694 | 0.507 | 0.518 | 0.566 | 0.715 | 0.600 |
| GRPO | 0.711 | 0.502 | 0.524 | 0.562 | 0.737 | 0.607 |
| HRPO (Ours) | **0.720** | **0.518** | **0.536** | **0.569** | **0.742** | **0.617** |
| **Qwen2.5-3B-Instruct** | | | | | | |
| SFT | 0.670 | 0.348 | 0.360 | 0.454 | 0.474 | 0.461 |
| Distilled CoT | 0.799 | 0.575 | - | - | - | - |
| PPO | 0.819 | 0.597 | 0.604 | 0.582 | 0.811 | 0.682 |
| GRPO | 0.834 | 0.602 | 0.604 | 0.601 | 0.814 | 0.691 |
| HRPO (Ours) | **0.845** | **0.613** | **0.630** | 0.590 | **0.820** | **0.700** |

3B HRPO 의 평균은 0.700 으로, 표 안 7B 이상 모델 가운데 가장 높은 Qwen2.5-7B (0.635) 와 MAmmoTH2-8B (0.652) 를 모두 앞선다. 5개 지표 중 4개에서 동일 백본 PPO·GRPO 를 모두 누르고, GSM8k 에선 +1.1%p (PPO 대비 +2.6%p), MATH 에선 +1.1%p (PPO 대비 +1.6%p) 가 추가된다. 유일하게 GRPO 가 앞서는 MMLU-STEM (0.601 vs 0.590) 은 객관식 위주라 reasoning depth 의 차이가 잘 드러나지 않는 도메인이다.

1.5B HRPO 의 평균 0.617 도 의미가 작지 않다. MATH 에서 0.518 로, 약 5배 큰 Qwen2.5-7B 의 0.498 보다 +2.0%p 위다. MATH500 의 0.536, GSM8k 의 0.720 은 sub-7B 모델 중 표 안 최고치이다. 1.5B SFT 의 0.433 과 비교하면, 같은 가중치에서 RL 학습만으로 0.184 (+42%) 만큼 끌어올린 셈이다.

SFT < distilled CoT < RL 의 순서는 두 사이즈에서 동일하게 유지된다. 수학·과학 도메인에선 정답 자체가 검증 가능한 verifiable reward 라 RL signal 의 노이즈가 작고, 그래서 RL 이 SFT·증류 방식보다 안정적으로 더 멀리 간다. HRPO 의 마진은 PPO·GRPO 대비 평균 1.0~1.5%p 수준으로 지식 영역만큼 크진 않지만, MATH 처럼 단계 수가 깊은 문제일수록 격차가 살짝 더 벌어진다는 점은 동일하다.

비교 표에 distilled CoT 의 MATH500·MMLU-ST·ARC-C 점수가 비어 있는 것은 원논문이 보고하지 않아서다. GSM8k·MATH 만 비교해도 HRPO 가 두 사이즈에서 모두 distilled CoT 를 앞선다는 신호로 충분하다 (1.5B: 0.720 vs 0.706, 0.518 vs 0.503 / 3B: 0.845 vs 0.799, 0.613 vs 0.575).

## 작은 모델일수록 이득이 큰 이유

두 카테고리 결과를 겹쳐 보면 한 가지 패턴이 또렷하다. 백본이 작을수록 HRPO 가 같은 RL 가족 (PPO·GRPO) 대비 얻는 마진이 커진다. 지식에서 1.5B 의 PPO→HRPO 가 +3.0%p, 3B 는 +2.9%p 로 비슷해 보이지만, GRPO→HRPO 로 잡으면 1.5B 는 +7.6%p (0.261→0.337) 이고 3B 는 +1.3%p (0.367→0.380) 로 차이가 분명하다. STEM 에서도 GSM8k 기준 1.5B 의 GRPO→HRPO 격차 (+0.9%p) 보다 작은 모델일수록 도전 난이도가 높아 marginal gain 이 더 잘 드러난다.

해석은 어렵지 않다. 작은 모델은 한 토큰이 담을 수 있는 정보가 제한되어, 같은 길이의 CoT 를 만들어도 추론에 필요한 latent state 가 충분히 정제되지 않는다. HRPO 가 매 스텝 hidden state 를 직접 다음 입력으로 흘려주는 hybrid latent 구조는, 좁은 표현 공간을 폭이 아니라 깊이로 보강하는 효과를 낸다. 7B 급에서는 이미 representation 이 풍부해 한계 효용이 줄지만, 1.5B·3B 에선 그 구조 자체가 결정적인 차이로 이어진다.

결국 이 편의 표가 보여주는 핵심은 단순하다. HRPO 는 더 작은 백본에 7B 급 reasoning 능력을 끌어내는 RL 레시피다. 다음 편에서는 학습 동역학과 잠재 토큰 분포를 들여다보면서, 왜 이 레시피가 실제로 그렇게 작동하는지를 본다.
